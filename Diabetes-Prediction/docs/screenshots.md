# Screenshots

All images below are generated by `model/evaluate_model.py` and saved into
`/screenshots`. Re-run that script any time `data/diabetes.csv` changes to
regenerate them.

## EDA plots

| File | Description |
|---|---|
| `01_histograms.png` | Distribution of each of the 8 clinical features. |
| `02_correlation_heatmap.png` | Pearson correlation between every feature and `Outcome`. |
| `03_outcome_countplot.png` | Class balance between diabetic and non-diabetic records. |
| `04_boxplots.png` | Spread of each feature split by outcome. |
| `05_distribution_by_outcome.png` | KDE plots comparing feature distributions between classes. |

## Model evaluation plots

| File | Description |
|---|---|
| `06_feature_importance.png` | Feature importances from the selected (tree-based) model. |
| `07_confusion_matrix.png` | Confusion matrix of the best model on the held-out test set. |
| `08_roc_curve.png` | ROC curve and AUC of the best model on the held-out test set. |

## Application screenshots

Add screenshots of the running desktop app here after your first run, e.g.:

- `app_login.png` — Login screen
- `app_register.png` — Registration screen
- `app_dashboard.png` — Dashboard overview with stat cards
- `app_prediction.png` — Prediction form and result panel
- `app_history.png` — Prediction history list with search/export

Since this environment cannot render a live Tkinter window, these should be
captured locally after running `python app/main.py` and dropped into
`/screenshots`, then linked from the main `README.md`.
