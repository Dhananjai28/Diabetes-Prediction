Machine-Learning Powered Prediction
DiabetesCare AI

This application predicts a patient's likelihood of diabetes using a machine-learning model trained on the Pima Indians Diabetes Dataset. Six classifiers (Logistic Regression, Decision Tree, Random Forest, SVM, KNN, and Gradient Boosting) were trained and compared; the best-performing model by F1 score is used for live predictions.

This web application shares the exact same database, trained model, validation rules, and PDF report generator as the desktop (CustomTkinter) version of this app — both are simply different interfaces onto the same backend.

Tech Stack

Python, Flask, Flask-Login, scikit-learn, Pandas, NumPy, Bootstrap 5, Chart.js, SQLite.

Important Note

This tool is for educational and portfolio purposes only and is not a substitute for professional medical diagnosis.
